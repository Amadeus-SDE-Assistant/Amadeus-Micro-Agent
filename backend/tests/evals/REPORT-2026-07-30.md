## Notes

1. The one miss — "Can you store my work history so we can use it later?" routed to
   `none` — is defensible agent behavior: no resume content was provided, and the
   agent asked for it instead of calling a storage tool with nothing to store. The
   golden case now accepts both answers.
2. The SDK emitted `CanUseToolShadowedWarning` for the four read-only tools,
   confirming the P6 security finding from the SDK's own mouth: `allowed_tools`
   entries auto-approve before `can_use_tool` is consulted. For our design this is
   intended (read-only tools skip the gate); the warning documents why write tools
   must never be listed there.
